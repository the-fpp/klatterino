# klatterino

Klatterino is an unofficial Chatterino fork with experimental platform support.
It supports Windows and Linux.

> **Disclaimer:** This is a joke project. It is not affiliated with Chatterino
> and should not be mistaken for an official build.

[Download the latest release](https://github.com/the-fpp/klatterino/releases)

## What you get

- Chatterino with the project's bundled changes.
- Windows and Linux portable builds when published with a release.

## Before you try it

Alpha builds are for testing. Keep your normal Chatterino install and profile
available, and report problems with the release version and your platform.

## Plugin bundle

Includes a plugin to control Streamlink and a plugin for Streamlink to add
platform support.

- mpv
- Streamlink

For Rumble-specific setup, see the [Rumble user guide](deps/chatterino7/docs/rumble-user-guide.md).
